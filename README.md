# Araχne
🇵🇱 Prosty algorytm do liczenia rymowalności wyrazów w języku polskim.

🇬🇧 A simple algorithm for quantifying how much two strings rhyme in Polish.

> ⚠️ This program is still in the "experimental" stage and is before empirical confirmation. The aim of the current version is to use a single metric to reliably discriminate between rhymes and non-rhymes. More sophisticated functions are still to be implemented.
